## What is included

Every domain and difficulty is included. “Exclude Active Questions” was off, so questions from full-length practice tests are included. College Board presents PSAT/NMSQT and PSAT 10 together as one assessment.

The PDFs retain the official question IDs, assessment, section, domain, skill, difficulty, passages, answer choices, mathematical notation, diagrams/tables, correct answers, and explanations supplied by the export. These are **teacher/reference copies with answers**, not answer-free student worksheets.

## Verification and index

- [Question index](question-index.csv): question IDs and their PDF file/page locations.
- [Manifest](manifest.json): file checksums, page counts, question IDs, and per-section count reconciliation.
- All six assessment/section totals match the live search totals exactly. There are no duplicate IDs within any assessment/section.
- There are 10,458 globally unique IDs across 10,458 entries. Cross-assessment overlap, if any, is retained rather than deleting questions from an assessment.
- Every PDF was opened and its question headers were counted. Representative Reading and Writing, table, and Math pages were rendered and visually checked. The official PDF contents were not rewritten.

The current official bank’s total differs from the earlier SATStation count. This repository follows College Board’s current inventory.
