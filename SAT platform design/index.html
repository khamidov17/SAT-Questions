Flow notes

  • First visit: Home shows no completed exams, zero questions answered, and no accuracy percentage until a test is submitted. Browse mock exams remains the primary action.
  • Start exam opens directions before the first question. During a test, answer selection and numeric entry are saved locally. More contains save and exit; resuming returns to the saved question.
  • The center question navigator opens a grid for the current module, including answered, unanswered, and marked states. No correctness is revealed during a live exam.
  • Earlier modules continue to the next module or the planned section break. Only the final module has the final Submit test confirmation shown here. This practice transition is a product decision, not a claim about official test-day behavior.
  • Submitted answers are read-only. Review includes explanations and navigation, then returns to results. Numeric answer review uses the same review shell with submitted value and accepted answer in place of choices.

Reference and design boundaries

The supplied Makon reference informed the roomy sidebar structure; the supplied Bluebook reference and official screenshots informed the exam workspace. The navy/blue theme, dashboard, catalog, profile, submission confirmation, results and explanations are SAT Practice design adaptations. No official affiliation is implied.

  • College Board administration reference: pages 140, 144, 146–147 inspected for Math tools, numeric entry, navigation and review layout.
  • Official Bluebook tools
  • Official My Practice overview: official post-test review is separate from the exam workspace.

Mock questions are original illustrations. Sample results are counts and rounded accuracy, not validated SAT score predictions. These images do not validate adaptive routing, tool functionality, accessibility, mobile layouts, persistence, or student willingness to pay. Selected answer circles and some spacing are visual approximations that need precise treatment if a design is later implemented.
